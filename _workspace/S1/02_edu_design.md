# S1 EDU DESIGN
- 평가 유형: 계산값 입력 = FORMATIVE (maxAttempts null, showAnswerAfter NEVER — 정답값 대신 error_type만)
- 진단 메시지: 프로토타입 문구 유지(행동 지목 + 이유), 금지어 없음("틀렸습니다" 등). 예: "고체는 물에 넣기 전에 먼저 질량을 재야 해요."
- 오류 유형(밀도): swapped(부피÷질량) / unit / meniscus(부피 ±0.5 오독) / decimal(10배) / rounding / other
- 변인 블록: 독립·종속·통제변인, 실험 집단, 비교 집단, 측정 방법 — 학생이 선택지 + 근거(선택) 입력, 절차와의 불일치를 진단(지침 2.3)
